NetSim Tutor model CDN

This Cloudflare Pages project serves the NetSim tutor model artifacts from a public Backblaze B2 bucket through Cloudflare's edge (free egress, cached, CORS-enabled for in-browser inference).

Model files are under /m/<version>/<file>, e.g. /m/latest/manifest.json.

Not a user-facing site — see NetSim.
